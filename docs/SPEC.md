# Blockfall app: spec

The game itself (rules, feel, layout, scoring, boosts/power-ups, themes, audio) is specified once in `game-factory/games/blockfall/docs/SPEC.md` (SH1, owner 2026-11-21). This app is a container: it shows the game and provides its shop, coins, Remove Ads, ads, share, leaderboard and release setup through `BlockfallServices`. The shop, monetisation and store sections that used to be here now live in the game's SPEC next to the game.
